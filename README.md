# FNAFJumpscare
This is a BepInEx mod for Gorilla Tag that has a 1/400 chance to play a FNAF jumpscare every second.

## Installation
1. Download the latest `FNAFJumpscare.dll` from the [Releases page](https://github.com/quoote/FNAFJumpscare/releases)
2. Place the `FNAFJumpscare.dll` file in your `BepInEx/plugins` folder
3. Launch the game, and thats it

## Additional Info
Custom jumpscares may be added if you build the mod yourself
